# Scripts Folder

This folder contains all final-round execution docs.

## Files

1. PORTAL_SUBMISSION_CHECKLIST.md
   - Form submission order and link checks.

2. FINAL_DEMO_VIDEO_SCRIPT.md
   - Final narration script for recording.

3. DEMO_DAY_RUN_ORDER.md
   - Time-bound run sequence and role split.

4. WINNING_SLIDE_ORDER_AND_TALK_TRACK.md
   - Slide-by-slide words aligned with final deck.

5. JUDGE_QA_DEFENSE_CHEATSHEET.md
   - Controlled answers for likely judge questions.

6. _build_final_deck.py
   - Script used to generate the new final deck from evidence files.
