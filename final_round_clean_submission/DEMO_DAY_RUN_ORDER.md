## T-20 minutes

1. Launch app
2. Open deck
3. Open notebook
4. Open benchmark and evidence JSON files

## T-15 minutes

1. Verify app metrics match evidence
2. Verify notebook runs end-to-end
3. Verify deck slide count <= 10

## T-10 minutes

1. Assign speaker sequence
2. Lock final script sections
3. Check mic and screen recording

## T-5 minutes

1. Re-open all public links in incognito
2. Freeze edits
3. Start recording

## Live sequence

1. Intro and problem
2. Best model results
3. Benchmark deltas
4. Inference trace
5. Reproducibility notebook
6. Closing

1. Quick playback for audio clarity
2. Upload video
3. Verify public access
4. Final portal submit
