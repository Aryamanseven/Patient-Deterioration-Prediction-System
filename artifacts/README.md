# Artifacts Folder

This folder stores generated outputs from training and evaluation runs.

## Layout

1. run_* directories
   Each pipeline execution writes to a unique run folder.

2. evidence_latest_run.json
   Machine-readable evidence snapshot with metrics and artifact hashes.

3. Supplemental run metadata
   Optional logs or summaries generated by helper scripts.

## Core vs advanced artifact expectations

Core run outputs (required for baseline completion):
1. model/dl_model_final.pt
2. model/model.cbm
3. model/scaler.pkl
4. model/ensemble.pkl
5. model/feature_columns.json
6. metrics.json
7. predictions.csv
8. ssl_pretrained_tcntransformer.pt (required when SSL is enabled or reused)

Advanced outputs (when FL + DG + XAI are enabled):
1. fl_rounds_history.json
2. lodo_results.csv
3. top_features.csv
4. shap_summary.png
5. captum_temporal_heatmap.png

## Dependency notes

1. `pipelines/run_full_pipeline.py` writes run artifacts here.
2. `pipelines/audit_artifacts.py` validates completeness from this folder.
3. `dashboard/app.py` selects latest complete run data from this folder.
4. Package builders read this folder to construct evaluator bundles.

## Cleanup policy

1. Keep only latest successful runs in active artifacts.
2. Move failed or retry runs to archive/ rather than deleting immediately.
3. Keep audit logs and latest pipeline log for debugging.

## Notes

Do not hand-edit run files. They are generated outputs and should be treated as immutable evidence.
