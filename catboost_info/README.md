# catboost_info Folder

This folder is auto-generated by CatBoost during training.

## Typical contents

1. catboost_training.json
2. learn_error.tsv
3. test_error.tsv
4. time_left.tsv
5. TensorBoard event files in learn/ and test/

## Dependency notes

1. No downstream runtime component requires this folder for inference.
2. Pipeline success criteria are based on files in `artifacts/run_*/`, not `catboost_info/`.

## Operational guidance

1. Safe to delete between runs if you need cleanup.
2. Not required for final inference artifacts.
3. Useful when diagnosing CatBoost training instability.

## Sharing guidance

1. Include only when debugging model training behavior.
2. Exclude for lightweight handoff if disk footprint matters.
