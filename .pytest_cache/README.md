# Pytest Cache Folder

## Purpose

This folder is auto-generated by pytest to cache metadata for faster local test runs.

## What it contains

1. Last-failed test cache used by `--lf` and `--ff`.
2. Small metadata entries for test session acceleration.

## Dependency impact

1. No runtime code depends on this folder.
2. Deleting it does not affect model training, pipeline execution, or dashboard behavior.

## Sharing guidance

1. Treat this folder as local-only cache state.
2. Do not rely on this folder for reproducibility evidence.
3. Keep it ignored in git workflows when possible.
