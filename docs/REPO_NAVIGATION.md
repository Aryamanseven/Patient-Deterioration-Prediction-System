# Repository Navigation (Evaluator-Friendly)

Use this file to avoid getting lost in the project tree.

## If you have 5 minutes

1. Read README.md for run commands and structure.
2. Open docs/ANC052_STRENGTHS_WEAKNESSES.md.
3. Open artifacts/evidence_latest_run.json for proof-style summary.

## If you are a technical evaluator

1. Architecture: docs/ARCHITECTURE.md
2. Module wiring: docs/MODULE_CONNECTIONS.md
3. Pipeline logic: pipelines/run_full_pipeline.py
4. Feature engineering: core/features.py

## If you are a product or judge evaluator

1. Pitch narrative: submission/PITCH_SCRIPT.md
2. Submission notebook: submission/Patient_Deterioration_Week1_Official_Submission_Notebook.ipynb
3. Dashboard app: dashboard/app.py

## Where metrics and proof live

1. Run metrics: artifacts/run_*/metrics.json
2. Predictions: artifacts/run_*/predictions.csv
3. Audit report: artifacts/final_audit_*.json or pipelines/audit_artifacts.py output
4. Evidence export: artifacts/evidence_latest_run.json
